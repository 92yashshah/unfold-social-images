# Unfold social images

Ready-to-post images for Unfold Football's Buffer drafts. Buffer reads each image from its link here at posting time, so do not delete or rename an image until its post has gone out.

- `posts/`: one JPEG per post, named `<date>_<template>_<player>_<version>_<platform>_<random>.jpg`. The random part keeps links hard to guess.
- Source of every image: `Work/Social/output/ready-to-post/` on Yash's Mac.
